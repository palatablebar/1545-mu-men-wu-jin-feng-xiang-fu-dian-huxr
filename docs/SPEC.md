# 木门五金封箱复点数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `scan_count` | 扫码累计 | 次 | 2–36 |
| `expected` | 应装配件 | 件 | 3–33 |
| `mass_g` | 箱内五金重量 | g | 150–5300 |
| `variant` | 非标配件类型 | 类 | 0–10 |
| `partial` | 补领单数 | 单 | 0–9 |
| `scan_repeat` | 重复扫描 | 次 | 0–14 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。标签 0 为已核实正常，1 为需要复核的实绩。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 手持扫条 | `barcode_reads` | 扫码枪累计 | 1 | 0 |
| 手持扫条 | `bom_parts` | 门套应装数 | 1 | 0 |
| 应装清册 | `mass_mg` | 关箱五金总毫克 | 1000 | 0 |
| 应装清册 | `nonstandard_sku` | 异形件库号数 | 1 | 0 |
| 磅重补领 | `counter_issue` | 补领签次数 | 1 | 0 |
| 磅重补领 | `second_reads` | 第二次扫描数 | 1 | 0 |

示例见 `sample_data/packing_plans_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[1,40)`、校准 `[43,62)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `unit_mass` | 应装件均重 | `mass_g/expected` |
| `missing_ratio` | 可能缺件占比 | `max(0,expected-scan_count+scan_repeat)/expected` |
| `variant_density` | 非标件浓度 | `variant / expected` |
| `scan_density` | 重复扫占比 | `scan_repeat / scan_count` |
| `reissue_ratio` | 补领占比 | `partial / expected` |

### PAM 箱型聚类

在已核对常态箱上按 L1 度量选择实际箱单作为中心。推断将与最近中心的差异换算为可校准的离群分。

本工作台的独立样本校准方式为箱距频数合并。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较训练邻域距离。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 下发封箱复点

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `REPEAT_SCAN` | `scan_repeat >= 11 and scan_count <= 16` | 有效扫码数须复核 |
| 2 | `HEAVY_KIT` | `mass_g >= 3800 and expected <= 10` | 重量与应装数不符 |
| 3 | `VARIANT_COUNT` | `variant >= 7 and partial >= 3` | 非标件补领复点 |

第一条为暂停规则。其余命中与模型阈值 `0.57` 共同决定是否列入候选。单据所需工位数按 `1 + int(expected >= 17)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 改单、留位与封签名单

补扫或重称形成新版改单时，只允许复用本班已冻结的特征填补、PAM 中心、校准和邻域基线重算，不得把新读数回流到训练窗口。已分派箱只要未变成 `暂停` 或 `人工判读`，即使风险降到阈值以下也保留工位；变成这两类状态时立即收回工位，再按原候选顺序补入满足分区额度、标签争议和台位限制的候补。

版次只增不退：旧版晚到返回 `OLDER_REVISION` 且不覆盖当前单；同版读数不一致返回 `CONFLICTING_REVISION`，工位和原处置保持不变并挂起核对。相同 `Idempotency-Key`/`request_id` 的重试返回同一份派单，不再次占用工位。封签导出必须由最终 `Plan` 和同一组展示行生成，并通过工位余额、状态数量和已分派工位的双重核对。

## 封箱差分簿

重复扫描次数从累计扫码扣除，余量与应装件数核对。只有同工位同箱型至少三只账实一致的箱单才提供重量参照。重量只用于核对。 在派发环节展开现场安排，或从关联单据回查实际读数。
